## Лабораторна робота № 9. Функції в Python

Задача: дано сторони трикутника `a`, `b`, `c`, знайти площу за **формулою Герона**. Як у методичці,
її розв'язано двома способами:

- `lab9.py` — **файл-програма (скрипт)**: вводить сторони й обчислює площу прямо в коді;
- `heron.py` — **файл-функція (модуль)** з функцією `heron_area(a, b, c)` і довідкою (docstring),
  яку показує `help(heron.heron_area)`;
- `lab9_module.py` — програма, яка імпортує модуль (`import heron`) і викликає функцію в циклі
  для кількох трикутників.

```
p = (a + b + c) / 2
S = √( p(p − a)(p − b)(p − c) )
```

Сторони можуть бути дробовими. Перед обчисленням перевіряється, що трикутник існує:
усі сторони додатні й кожна менша за суму двох інших. Інакше виводиться «Такого трикутника не існує».

| a, b, c | S |
|---------|---|
| 3, 4, 5 | 6.0 |
| 5, 6, 7 | 14.697 |
| 1, 2, 10 | трикутник не існує |
