## Лабораторна робота № 9. Функції в Python

Програма вводить три сторони трикутника `a`, `b`, `c` і обчислює його площу за **формулою Герона**:

```
p = (a + b + c) / 2
S = √( p(p − a)(p − b)(p − c) )
```

Сторони можуть бути дробовими. Перед обчисленням перевіряється, що трикутник існує:
усі сторони додатні й кожна менша за суму двох інших. Інакше виводиться «Такого трикутника не існує».

| a, b, c | S |
|---------|---|
| 3, 4, 5 | 6.0 |
| 5, 6, 7 | 14.697 |
| 1, 2, 10 | трикутник не існує |
