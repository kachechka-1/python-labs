## Лабораторна робота № 9. Функції в Python

Програма вводить три сторони трикутника `a`, `b`, `c` і обчислює його площу за **формулою Герона**:

```
p = (a + b + c) / 2
S = √( p(p − a)(p − b)(p − c) )
```

Сторони можуть бути дробовими. Перед обчисленням перевіряється, що трикутник існує:
усі сторони додатні й кожна менша за суму двох інших. Інакше виводиться «Такого трикутника не існує».

| a, b, c | S |
|---------|---|
| 3, 4, 5 | 6.0 |
| 5, 6, 7 | 14.697 |
| 1, 2, 10 | трикутник не існує |

## Лабораторна робота № 10. Розгалуження в Python

Обчислення кусково-заданої функції (варіант 4) через `if … elif … else`:

```
      ⎧ 2.3·∛(x − 1.3) + sin²x,      x > 2
y =   ⎨ arccos(x/2) + 2^(3x),        −2 ≤ x ≤ 2
      ⎩ |x|^(sin x) − lg|x + 1.5|,   x < −2
```

Кубічний корінь обчислюється через `math.cbrt` (правильно працює і для від'ємних чисел),
`lg` — через `math.log10`, модуль — через `abs`. Подвійна умова записана скорочено: `-2 <= x <= 2`.

| x | Гілка | y |
|---|-------|---|
| 3 | x > 2 | 2.76493 |
| 2 | −2 ≤ x ≤ 2 | 64 |
| 1 | −2 ≤ x ≤ 2 | 9.04720 |
| −2 | −2 ≤ x ≤ 2 | 3.15722 |
| −3 | x < −2 | 0.68029 |

результати збігаються.
